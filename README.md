# Mushroom Edibility Classification

A machine learning classification project to predict whether a mushroom is **edible or poisonous** based on its physical characteristics.

## Problem Statement

The objective is to build a binary classification model that predicts mushroom edibility from various physical attributes.

- **Target:** Edible (`e`) or Poisonous (`p`)
- **Type:** Binary Classification
- **Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Workflow

The project follows a complete machine learning workflow:

1. Data exploration and preprocessing
2. Handling missing values and duplicates
3. Feature engineering and encoding
4. Exploratory data analysis and visualization
5. Training multiple classification models
6. Model comparison using cross-validation
7. Hyperparameter tuning
8. Feature importance analysis
9. Final model selection and prediction

## Machine Learning Models

Multiple classification algorithms were evaluated, including:

- Logistic Regression
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Support Vector Machine
- Naive Bayes
- Gradient Boosting

## Model Evaluation

The models were compared using **5-fold stratified cross-validation**.

Hyperparameter tuning was performed on selected models to improve their performance and identify the best-performing approach.
